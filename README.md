# Khater Group Website

Corporate website for **Khater Group**, covering its five sectors: Sports, Aquatics, Tech, Scapes and Play.

## Features

- Animated hero slider with the Khater logo animation
- Services section with sector tabs and logos
- Responsive footer with contact details and social links
- Floating WhatsApp chat widget that sends a pre-filled message to the sales team
- Smooth GSAP animations and a clean Tailwind CSS design

## Tech Stack

- React
- Vite
- Tailwind CSS
- GSAP
- Lucide React

## Getting Started

```bash
# install dependencies
npm install

# start the dev server
npm run dev

# build for production
npm run build
```

## Project Structure

```
src/
  assets/logos/     # brand and sector logos
  components/       # Footer, WhatsAppChat, sections...
```
